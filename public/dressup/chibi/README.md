# ちびろき ファッションセレクトガチャ素材（12種類）

このフォルダへ、次の **2つの透過WebPファイル** をアップロードしてください。

- `chibi_layers_atlas.webp` — 4列×3行、12個の全身位置合わせレイヤー（2880×2160）
- `chibi_icons_atlas.webp` — 4列×3行、12個の単体アイテム画像（960×720）

各アイテムは、4列×3行のインデックス0〜11で参照します。
両ファイルをアップロードしてから `src/chibiGachaCatalog.ts` の
`CHIBI_GACHA_ASSETS_READY` を `true` に変更してください。
**画像未配置で true にすると、ガチャが空白のアイテムを排出します。**

アイテム番号:
1. 0 ドクターコートスタイル
2. 1 ねこフードパーカー
3. 2 リボンケープセット
4. 3 エアリーウルフ
5. 4 シースルーマッシュ
6. 5 ゆるまとめヘア
7. 6 やさしい瞳
8. 7 星きらめきアイ
9. 8 とろみスリープアイ
10. 9 ねこみみヘッドホン
11. 10 カプセルヘアピンセット
12. 11 ナースベレー帽

対応フォルム: `mature`（ちびろき立ち絵）。

実装：
- `src/chibiGachaCatalog.ts` — アイテム定義
- `src/ChibiAtlasTile.tsx` — アトラスから個々のパーツを描画
- `src/appearance.ts` — フォルム別着せ替えのレイヤー
- `src/RokiCharacter.tsx` — キャラクターへの重ね合わせ
- `src/GachaPrizeArt.tsx` — ガチャ景品の単体プレビュー
- `src/DressUp.tsx` — ガチャ獲得後の所持確認

**注意:** 参考立ち絵に対する位置合わせは試作段階です。正式版前に iPhone Safari で全12点の位置ズレをチェックしてください。
