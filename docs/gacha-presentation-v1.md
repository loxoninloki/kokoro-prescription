# ガチャ演出システム v1

対象: integration/kokoro-unified-v3。実装は効果音・表示レアリティ・動的獲得ポップアップのみ。

## 承認素材とタイムライン

- 使用: public/gacha/kokoro_gacha.gif。ユーザーがGitHubにアップロードした承認済み紫の医療ガチャ。
- 309×307px、16フレーム、各240ms、合計3840ms、1,115,382 bytes。
- SHA-256: e129bc6732d7e4f51f4943e94cbfdf27c9c6254072bf90f7c74e2954a9608050
- GIFメタデータは無限ループ（loop=0）。バイナリは承認素材のまま保持し、アプリが読み込み完了から3840msで取り外して1回分を表示する。各抽選IDのURLで先頭から再生する。
- フレームを確認した音・光の時刻: 起動0ms、回転480ms、減速1440ms、排出1920ms、開封2880ms、発光3360ms、結果3840ms。
- 読み込みエラー、8秒の読み込み待ち超過では確定済み結果へ進む。非表示からの復帰時には経過時刻を確認する。
- 端末の動き軽減設定ではGIFを再生せず、静かな十字と結果を表示。ユーザー操作のスキップ機能ではない。

## 効果音

Web Audio APIの正弦波・三角波を使った独自の音階と短いカプセル音。LUX Worksがこの実装のために制作。第三者の音源・サンプルを使用しない。

初期OFF。最終確認ボタンの同期イベント内でAudioContextを起動し、保存成功後、GIF onLoadから同じタイムラインで予約する。OFF・演出終了・画面離脱で全予約音を停止。非表示時も停止。音声が使えなくても抽選と結果表示は継続。設定は kokoro-gacha-audio-v1 に保存し、設定保存が失敗した場合は通知する。

## レアリティ

表示専用の APPROVED_ITEM_RARITIES は承認前のため空。全ての既存アイテムを「通常」へフォールバックさせる。normal / rare / highest の光・文字・音・ポップアップ基盤を用意。抽選対象・確率計算には使用しない。

承認用の分類案（未適用）:

| 区分案 | 候補 | 理由 |
| --- | --- | --- |
| 通常 | 基本の壁・床・机、ラグ | 基本の暮らしの装飾 |
| レア | 星ピン、ベレー帽、夜空の壁紙、ベッド、ランプ | アクセントとなる装飾 |
| 最高レア | 花あかり、月夜のきらめき、癒しの夕空 | 光や空間全体の特別演出に合う |

この案の確定にはユーザーの承認が必要。確定しても既存の排出確率は変えない。

## 抽選と表示の分離

confirmGachaDraw が既存の Web Locks / IndexedDB ロック内で既存 drawItem を1回実行する。既存の未所持対象・重み・価格はそのまま。消費・所持品・単一の未確認結果 pendingGachaResult を同じ報酬台帳の1回の保存に含める。保存失敗時は演出を開始しない。保存成功後の再抽選はない。

同期refで連打を防ぎ、演出中・結果未確認中は再抽選を禁止。別タブに未確認結果がある場合も新しい抽選を拒否する。再読み込み・画面遷移後はガチャを開いた際に保存済み結果を表示し、音とGIFを再実行しない。OKは一致する未確認結果だけを消し、所持品を保持する。OK保存失敗時には結果を閉じず再試行できる。

pendingGachaResult は「未確認の1件」だけで、履歴リストではない。既存バックアップは報酬台帳ごと保存するため、この任意フィールドも保持。古いデータにこのフィールドは必須ではない。

## お試し

カタログと獲得表示は GachaPrizeArt を共有。衣装は既存のレイヤー画像、家具は既存の家具アイコンを使用する。家具の写実的な商品画像は未整備のため追加しない。

GachaTryOn / trialEquipment / trialLayout を再利用。現在のフォルム・コーデ・ルームを入力し、仮表示だけを変更。対応しないフォルムは理由を表示して試着ボタンを無効化する。OKで閉じても所持は維持。

## 将来仕様（今回実装しない）

- ガチャ履歴: 抽選日時、ガチャ名、アイテム、レアリティ、使用通貨、消費量を新しい順に表示。スキーマバージョンと将来の同期・移行を設計してから実装する。今回は履歴画面・履歴ストアを追加しない。
- スキップ: 任意のスキップ操作と演出短縮設定。初回体験と利用者の設定変更を両立し、結果・確率に影響させない。今回は既存の明示的スキップ操作を除去し、速度設定も追加しない。
