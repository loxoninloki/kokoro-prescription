# ガチャ獲得プレビュー修正 v2

対象: integration/kokoro-unified-v3 / kokoro-prescription-dev。修正前 HEAD: 59b0dfee8cf05524bd56636b462a435758edd695。

## 原因と表示修正

配信中の獲得画面で星ピンのSVGは読み込み済み（naturalWidth > 0）だったが、親のgridの自動トラックと、絶対配置した子画像・幅100%のラッパーの組み合わせにより、ラッパーと画像が幅0px、高さ188pxになっていた。画像パスやフォルム制限が原因ではない。

獲得画像の枠を確定サイズの基準にし、アートをその枠全体へ絶対配置することで、gridの内在サイズ計算から分離した。375×640のブラウザ検証では、星ピンの実画像は幅278px・高さ178px。花あかりの花と光、月夜のきらめきの床と前面の両レイヤーを確認した。装備用の位置指定は単体画像には適用しない。図柄に重なる代用の装飾記号を削除し、読込失敗時はエラー文を表示する。

単体画像は全フォルムで閲覧・拡大可能。試着は対応フォルムのみ。種類は衣装一括表示から帽子・アクセサリー・エフェクトなどの正式カテゴリ表示へ変更。

## 着用保存

獲得結果とラインナップのお試しから、対応する正式所持の衣装・エフェクトを保存できる。保存直前に既存のWeb Locks / IndexedDBロック内で、保存済みのフォルム、正式台帳の所持、対応フォルムを検証する。最新のコーデへカテゴリ競合ルールを適用し、saveFormEquipmentで現在フォルムだけ更新する。他フォルム、通貨、所持品、ルーム配置は変更しない。保存内容を読み戻して確認してからAppへ反映し「着用しました！」を表示する。

テストモードでは着用保存ボタンを出さず、保存関数も拒否する。家具の仮配置は保存しない。試着・プレビュー・着用から抽選を呼ばない。

## 表示と音響

ガチャ一覧、選択中カード、演出GIF、獲得画像を拡大。幅320/375px、高さ640pxで横はみ出しなし。拡大時はモーダル内スクロールを許容し、OKへ到達できる。セーフエリアと100dvhを使用。

既存承認GIF public/gacha/kokoro_gacha.gif（3840ms）は変更しない。音は既存の独自Web Audio合成を調整し、静かなシンセパッドの和音、ベル、柔らかな回転音、排出音、獲得音で構成する。外部音源・新規ファイル不要。GIFの既存ステージ時刻で同期し、二重再生前にstop、OFF・終了・非表示・アンマウントで停止。初期ミュートと保存キーを維持。瞑想音源は変更しない。

## 検証

TypeScript、全単体テスト、本番ビルドを実施。単体テストでは正式所持、非対応、テスト品、保存失敗、他フォルム維持、並行操作、連打、画像拡大、全レイヤー描画、既存抽選・残高・試着・バックアップの回帰を確認する。

ブラウザで、錠剤フォルムの星ピン画像、花あかり、2層の月夜のきらめき、拡大、非対応時の試着無効化、正式所持エフェクトの保存・ホームへの表示を、実データと分離したキーの検証データで確認した。

iPhone Safari/PWAの実機、消音・音量・音色の聞こえ方、実機でのGIFと音の同期はろき様の確認待ち。画像・音源の追加素材は不要。
