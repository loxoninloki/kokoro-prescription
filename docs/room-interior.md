# ルーム・累積ログイン報酬 実装記録

作業先: feature/persistent-navigation。本番・既存プロトタイプは未変更。

## 実装内容
- ルームから模様替え。壁紙・床・机・ベッド・ラグ・ランプの固定スロット、即時配置・交換・解除、保存・リセット・キャンセル。
- 全進化フォルムで利用可能。到達済みフォルムをルーム専用に選択し保存。経験値・コーデには影響しない。
- 既存の日本時間ログイン台帳 loginDays を唯一の累積日数として利用。1/3/7/14/21/30日の家具を自動付与し、所持品と受取IDを保存。過去到達分も遡及付与。新たな日数カウンター・チケット付与処理は作らない。
- ホームのチェックイン領域・ルームから報酬一覧。7日ごとのチケット進捗と次の家具を表示。31日以降も既存チケットが続く。家具はテーブル追加で拡張できる。
- 新規保存キー kokoro-room-v1。アバター所持品とは分離。JSONバックアップに任意フィールド room/rewards を追加。旧v1バックアップも受入れ、新フィールド欠落時は既存情報を保持。復元の全キー書き込み失敗時は従来のロールバックを適用。
- 保存失敗・破損データを上書きせず表示。対応ブラウザはWeb Locksで更新を直列化。
- ショップ価格・ガチャ確率・経験値計算・マカロン計算は変更しない。

## 素材待ち・実装上の限界
家具・背景はCSSの色と名前による仮表示。正式なPNG/WebPレイヤー、サムネイルへの差し替えは素材到着後。
今回のメッセージには参考画像が実添付されていないため、文章の構成要件に基づく。独自キャラクターや他作品の素材を追加していない。
家具は固定位置で、キャラクターの移動範囲は中央に限定。ドラッグ・回転・複数同種家具は対象外。
未保存の下部ナビ移動は破棄確認、再読み込みにはブラウザ確認。履歴操作は既存ルーターを維持（編集中の履歴移動は保存されないため、保存後の利用を推奨）。

## 不足素材
基準キャンバス1200×1080px（横:縦=1.111）。全レイヤーを同じキャンバス・座標で制作。家具はRGBA透過、光は控えめ。原本PNG、配信用軽量WebP推奨。サムネイルは各256×256px透過。

|素材|用途・順序|透過条件|
|---|---|---|
|基本背景・壁紙3種|壁面・最背面。壁床境界は高さ45%|不透明可|
|床1種|境界45%以下、壁の後|上部透明、床部分不透明可|
|机|左7%・上43%・幅25%・高さ13%、背面家具|透明|
|ベッド|右4%・上45%・幅29%・高さ23%、背面家具|透明|
|ラグ|左25%・上70%・幅50%・高さ20%、キャラの背面|透明|
|ランプ|左9%・上29%・幅13%・高さ18%、背面家具|透明|
|観葉植物・ぬいぐるみ・壁飾り・窓・カーテン|将来枠。初期の獲得表には未登録|透明|
|ルームエフェクト|背景または前景、将来枠|透明|
|各サムネイル|アイテム一覧・報酬一覧|透明|

キャラクターは既存の承認済み全5フォルムを使用。新規制作不要。
