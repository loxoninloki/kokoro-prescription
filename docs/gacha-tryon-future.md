# ガチャラインナップ「お試しプレビュー」将来実装仕様メモ

対象: こころの処方箋 / integration/kokoro-unified-v3
状態: 構想・設計保留。別途承認まで実装しない。

## 概要
ガチャ一覧の「ラインナップを見る」で、衣装・インテリアの排出候補を見られる。
将来的には候補カードをタップしたとき、拡大画像に加えて「お試しする」を選び、手持ちでなくても装着・配置イメージを確認できるようにする。

### 衣装（コーデのお試し）
- 現在の選択済みフォルムと装備状態をベースにする。
- 仮の着せ替えはReactコンポーネントの一時状態だけで管理する。未所持品のプレビューは許可する。
- 試着したアイテムと既存装備が排他的なカテゴリでは重複表示しない。
- アイテムのsupportedFormsとレイヤー位置合わせ情報を遵守し、非対応フォルムでは実際と違う姿を誤表示しない。
- 閉じる・戻るで試着状態を破棄し、既存のコーデ保存データに変更を加えない。

### インテリア（ルームのお試し）
- 現在の保存済みルームを背景として使い、家具・壁紙を仮配置した状態をプレビューする。
- 当該アイテムのslotに限って一時的に上書きする。既存の保存済み配置は変更しない。
- 既存のRoomStageのレンダリングを再利用し、閉じれば元のルームへ戻る。

### UX・安全要件
- 「お試し」からは抽選や通貨消費が発生しない。購入・ガチャの抽選操作は別の最終確認画面で行う。
- 読みやすい「お試し中」表示と「元に戻す」操作を提供する。
- iPhone Safariの縦長画面、タップ操作、スクリーンリーダーへの対応を確認する。
- 試着状態はlocalStorageや報酬台帳、所有アイテムに保存しない。
- UIに使用する画像・位置合わせデータが不足する場合は、仮の見た目を完成品と誤認させず「プレビュー準備中」と明示する。

## 実装順（将来）
1. アイテム種別に応じたプレビュー起動
2. コーデのレイヤー合成（対応フォルムのみ）
3. RoomStageによる仮配置
4. iPhone実機確認・回帰テスト

本PRでは「ラインナップを直接開く」「抽選画面を簡略化する」までを行い、お試し機能自体は実装しない。
