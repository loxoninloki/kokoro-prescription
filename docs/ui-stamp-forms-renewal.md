# コーデ・インテリア・自動スタンプ・共通フォルム（2026-11-07）

作業ブランチ: `feature/persistent-navigation`。本番ブランチ・保存済みプロトタイプは未変更。

## 実装
- コーデ: 統一線画アイコン、メイン/詳細カテゴリの横スクロール、4列（320pxでは3列）の正方形サムネイル、独立した一覧スクロール、保存操作。編集中の選択と保存済み装備を別表示。
- 成熟前もコーデへアクセス可能。既存の周囲/足元エフェクトを全5フォルムとヒューマンで利用可能。帽子・星ピンは成熟用の位置合わせ素材しかないため、他フォルムでは非対応理由を表示して装備禁止。髪・目・衣服は引き続き分離素材待ち。未実装機能を完成扱いにしない。
- インテリア: 同じカテゴリ/詳細アイコン/グリッド/操作欄に統一。未所持は日数と無効状態を表示。固定位置のプレビュー、配置選択と保存済み配置を区別。リセット=保存済みへ戻す、初期状態=空の配置をプレビュー（元の初期配置が空室のため）。キャンセルと保存を維持。
- フォルム: 育成画面に解放済み/未解放の全6選択肢。Lv.1/10/20/30/50と、Lv.50のヒューマン。ホーム・ルーム・コーデ・育成は同一選択を参照。ルームのセレクターを撤去。レベル/XP/所持品を変えない。
- 自動スタンプ: 起動・フォーカス復帰・日付変更時に日本時間の当日を確認。手動チェックインボタンを履歴ボタンへ変更。保存完了後だけ当日枠の短い押印演出、実際のXP/マカロン/チケット/新規家具の受取内容を表示。同日再起動では表示しない。すぐ閉じる/スキップ、Esc、フォーカス循環、動きを減らす設定に対応。
- スタンプ帳: 累積順30日ごとの5列カレンダー、押印済み、家具の特別報酬、次のチケット/家具を表示。31日以降も7日チケットを継続。メニュー・ホーム・ルームから履歴を開く。

## 保存互換性と移行
既存キーとversion=1を維持。appearanceに任意フィールド `selectedFormId` と `formEquipment` を追加。既存 `equipped` は成熟コーデの互換フィールドとして保持。フォルム別装備は互いを上書きしない。旧ルーム選択はappearanceの選択がない場合にだけ移し、以後は共通選択を正とする。旧room.selectedFormIdは互換性のため保存データ内に残すが、操作UIと独立設定には使用しない。

チェックインの実在する日付と既存台帳loginDaysを照合し、大きい累積実績を維持。過去の日付を生成して埋めない。既存台帳に当日ログインだけ計上済みの場合、ログイン数・チケットを再加算せず当日のチェックインXPを一度だけ反映する。既存チェックインが当日を含む場合も再加算しない。日付不明の旧実績は従来の累積値として保持し、新しい独立カウンターは設けない。過去の7日報酬は再配布せず、次の新しい7日境界から従来処理で付与する。

XPと同数のマカロンは既存creditXpのイベントIDで重複を防止。チケットは既存registerLoginのみが付与。家具も既存報酬IDで重複を防止。

チェックイン・報酬台帳・ルームを共通ロック下で保存。Web LocksがないブラウザではIndexedDBのreadwriteトランザクションをロックに利用。保存直前の値を一時ジャーナルに記録し、保存失敗/中断時は復旧後に再試行。読み取り失敗時は成功表示・初期化をしない。

バックアップは既存appearance/room/rewardsに拡張情報を含む。旧バックアップも引き続き受け入れる。一時ジャーナルと押印の演出通知はバックアップ不要（確定した履歴から復元）。
