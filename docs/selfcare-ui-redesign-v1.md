## デザイン

「こころの処方箋 UIアニメーション四景.gif」の日記・カレンダー・歩数・お薬モックを参照。ラベンダー #C5B3D3、パープル #7754A8、ブルー #9CB8E8、白 #FAF7FF、背景 #EEE6F6、文字 #463457 を中心にしたカード型UI。既存の背景・線画アイコンを再利用。新規のサンプル記録はアプリに含めない。

SelfcareUI.tsx にカード見出し・進捗リングをまとめ、スタイルを selfcare-page 配下に限定。ホーム・ガチャ・コーデ・ルームやボトムナビは維持。入力文字は16px以上、主な操作は44px以上、ページ下余白は既存セーフエリア対応を利用。新規点滅・不要なアニメーションは追加しない。

## 4画面

- 日記: 保存済み気分・日付とやさしいメッセージ、5段階気分、2000字の入力欄、任意の追記チップ、保存、最近3件。「もっと見る」は既存カレンダー履歴へ。チップは元の文章を変えず末尾に追加し、保存は利用者が操作する。
- カレンダー: 従来の切替・スワイプ・日/月歩数グラフを維持。日記・気分・服薬・歩数の4種マーク、月の記録日数、選択日の実データ。0歩も記録あり。薬名は実登録から取得し、未登録IDの記録を架空の名称に置き換えない。
- 歩数: 今日の大きな数値、週間（月〜日）・従来の日別/月別グラフ、月間合計・記録日平均・最多日。未取得は「—／未取得」、0歩は「0」。既存の目標設定がないため目標機能は追加せず、リングは既存の5000歩報酬段階の指標と明記。ショートカットの受信確認を上部に表示し、明示的保存と従来の手入力を維持。
- お薬: 実登録から次の時刻と日本時間の残り分を計算。今日の記録済み予定は次候補から除外し、今日の残りがなければ明日の登録時刻を明示。登録時刻順の記録タイムライン、記録件数と進捗、登録・同じIDでの名称/時刻編集・非表示。編集で入力欄へ移動。未記録を飲み忘れと断定しない。

## 日付・集計

App既存の東京日付を受け取り、日付文字列の週・月演算はUTCで行うことで実行端末の地域に依存させない。服薬予定の時刻は Asia/Tokyo で計算。日付変更時は「今日」を選択中だった画面だけ新しい今日へ追従し、選択済み過去日は維持。

月間平均は保存済み日数で割り、未取得日を0歩に扱わない。最多歩数が同数なら最初の日を表示する。日記・気分・服薬・歩数の月間記録件数は、それらの記録がある日を重複なしで数える。

## データ保護

保存キー・JSON形式・XP関数・報酬台帳・育成解放条件・ガチャ・所持品・着せ替え・ルーム・認証は変更しない。変更対象の記録コンポーネントは従来の保存処理を利用する。服薬の表示名と時刻を編集しても同じ薬ID・過去のtakenキー・非表示状態を保つ。服薬報酬ロジックは既存のまま。

既存のバックアップ読込・復元テストと全ガチャ／育成関連テストも継続実行する。テスト用データは自動テストと隔離されたローカルブラウザ用名前空間だけに置き、開発版の利用者データへ注入・初期化しない。
