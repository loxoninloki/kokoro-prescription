# コーデ画面改修（2026-11-07）

作業ブランチ: feature/persistent-navigation。本番・保存キー・バックアップ形式は変更しない。

## 実装
大きなプレビュー、横スクロールの5カテゴリ、実在パーツに合わせた詳細分類、4列グリッド、独立スクロールの一覧、常時表示の保存操作。帽子・星ピン・エフェクトは組み合わせて装着・解除できる。
リセットは保存済み装備へ戻す。初期装備は追加パーツを外す。未保存の移動確認は既存処理を維持。
ショップ・ガチャ共通 ownedItemIds を参照し、累積記録報酬と保存済み装備の使用権を保持。価格・確率・残高・XP処理は変更しない。
新規取得履歴が未実装のためNEW表示は付けない。価格等未確定の購入・抽選は従来どおり停止中。

## 追加素材が必要な機能
現モデルは髪・目・衣服・アクセサリーが一体の完成画像。ヘア・メイク・ファッションの実際の交換は未実装で、準備中表示にしている。
共通キャンバス1024×1200px、RGBA透過PNG/WebP、同じ斜め角度・体型・固定座標で以下を用意する。これは制作推奨サイズであり、既存原本と合わせて最終調整する。

|素材|順序|必要条件|
|---|---:|---|
|背景エフェクト|10|全身の背面|
|後ろ髪|12|帽子対応差分も同じ座標|
|背面バッグ等|14|体の背面|
|素体|20|顔の輪郭・手足、衣服に隠れた部分も補完|
|ボトムス|22|素体に合わせる|
|靴|24|足首位置を固定|
|上着|26|腕・胴体位置を固定|
|目・顔|28|顔の輪郭は固定、顔と瞳の二重描画を避ける|
|前髪|30|後ろ髪と同一アイテムIDで連動|
|帽子|32|前後分割と髪のマスクを確認|
|前面アクセサリー|34|カプセルピン、ピアス、ヘッドホン、バッグを個別透過|
|前面エフェクト|36|足元の前後関係を確認|
|各サムネイル|—|256×256px、透明、余白を抑える|

初期衣装一式＋各部位1種類の差分を用意する。上の順序は新素材用の推奨値。現行の承認済み帽子・円エフェクトの座標・前後分割は維持している。
